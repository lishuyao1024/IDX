# Tableau Dashboards

Interactive dashboards developed during Weeks 8–10 of the IDX Exchange Data Analyst Internship.

| Dashboard | Description | Link |
|---|---|---|
| California Residential Market Analysis | Explore housing prices, market activity, days on market, and county-level market conditions. | [View on Tableau Public](https://public.tableau.com/app/profile/shuyao.li4777/viz/CaliforniaResidentialMarketAnalysis/CountyMarketConditions) |
| California Residential Real Estate Competitive Analysis | Explore Top 100 listing agents and offices, sales volume, closed units, and ZIP-code market maps. | [View on Tableau Public](https://public.tableau.com/app/profile/shuyao.li4777/viz/competitive_analysis_17891563158100/Top100ListingOffices) |

## Available Filters

The dashboards support interactive exploration using:

- Month
- City
- County
- ZIP code
- Property subtype

## Data Privacy

Raw and processed MLS datasets and packaged Tableau workbook files are not stored in this public GitHub repository.
